# Shou-Tzu Han — Academic Profile

A concise academic profile for research internship and postdoctoral opportunities. The site highlights work in trustworthy AI, LLM robustness, mechanistic interpretability, agentic retrieval, and reliable AI systems.

## Local preview

Requires Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The static GitHub Pages site is generated in `dist/client/`.

## Publish on GitHub Pages

1. Name the GitHub repository `<your-github-username>.github.io`.
2. Push this project to the repository's `main` branch.
3. In the repository, open **Settings → Pages** and choose **GitHub Actions** as the source.
4. The included workflow builds and publishes the site automatically.

The public address will be `https://<your-github-username>.github.io`.
